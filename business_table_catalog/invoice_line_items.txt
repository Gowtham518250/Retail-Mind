TABLE: invoice_line_items


PURPOSE: Product-level details for invoices. Use this table for questions about items, quantities, and line values on bills; invoice headers alone do not contain those details.

COLUMNS:
- id (integer, primary key): Line-item ID.
- invoice_id (integer, required): Parent invoices.id.
- product_id (integer, nullable): Related products.id when matched to a catalog product.
- description (string, nullable): Item description as written on the invoice.
- quantity (numeric 12,3, required): Quantity billed.
- unit_price (numeric 10,2, required): Price per unit.
- line_total (numeric 10,2, required): Total value for the line.

RELATIONSHIPS:
- invoice_line_items.invoice_id -> invoices.id -> invoices.user_id for shop isolation.
- product_id -> products.id when present; product link can be null.

QUERY GUIDANCE:
- Apply shop scope through the parent invoice.
- Sum quantity for units billed; sum line_total for item-level billed value.
- Do not count line rows as invoices; count distinct invoice_id when asked for invoice count.
- Respect invoice status/date filters from invoices for period and cancelled/draft handling.

RETRIEVAL TERMS: invoice items, line items, billed products, products on invoice, invoice quantity, item quantity, unit price, line total, bill details.

EXAMPLE QUESTIONS:
- Which products were on invoice INV-123?
- How many units of each product were invoiced this month?
- What is the total billed value by product?
