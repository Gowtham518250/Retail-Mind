TABLE: loyalty_transactions


PURPOSE: Loyalty point events for earning, redemption, adjustment, and expiration.

COLUMNS:
- id (integer, primary key): Loyalty transaction ID.
- customer_loyalty_id (integer, required): Parent customer_loyalty.id.
- transaction_type (enum, required): EARN, REDEEM, ADJUST, EXPIRE.
- points (integer, required): Points amount for the event.
- reference_id (string, nullable): Business reference such as invoice_id or sale_id.
- notes (text, nullable): Transaction notes; may contain free text.

RELATIONSHIPS:
- customer_loyalty_id -> customer_loyalty.id -> customers.id for shop scope.
- No transaction timestamp is defined on this model; do not answer date-range or chronology questions from this table alone.

QUERY GUIDANCE:
- Group points by transaction_type; confirm sign conventions before computing net points.
- Avoid exposing notes or reference IDs unless needed and authorized.

RETRIEVAL TERMS: loyalty transaction, points earned, points redeemed, point adjustment, expired points, rewards history.

EXAMPLE QUESTIONS:
- How many loyalty points were earned versus redeemed?
- Show loyalty point totals by transaction type.
- Which invoices are referenced by loyalty point events?
