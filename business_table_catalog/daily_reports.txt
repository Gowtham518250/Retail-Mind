TABLE: daily_reports


PURPOSE: Stored daily business summary values, including revenue, expenses, profit, bill count, top product, and collection totals.

RELATIONSHIPS:
- top_product_id -> products.id when a top product is recorded.
- user_id scopes the report to a shop account; it references user_details.id.

COLUMNS:
- id (integer, primary key): Report ID.
- user_id (integer, required): Shop/owner scope; apply authenticated shop filter.
- report_date (date, required): Business report date.
- total_revenue (numeric 12,2, default 0): Revenue value stored in the report.
- total_expenses (numeric 12,2, default 0): Expense value stored in the report.
- total_profit (numeric 12,2, default 0): Profit value stored in the report.
- bill_count (integer, default 0): Bill count.
- top_product_id (integer, nullable): Related products.id.
- top_product_name (string, nullable): Top product display name.
- top_product_qty (integer, default 0): Quantity for the top product.
- cash_collected (numeric 10,2, default 0): Cash collection total.
- upi_collected (numeric 10,2, default 0): UPI collection total.
- card_collected (numeric 10,2, default 0): Card collection total.
- whatsapp_sent (boolean, default false): Whether report was sent through WhatsApp.
- whatsapp_sent_at (datetime, nullable): Send timestamp.

QUERY GUIDANCE:
- This is a stored aggregate snapshot, not raw transaction data. Use it for report retrieval; use source tables to independently recompute details.
- Confirm how total_profit is calculated before explaining it as accounting profit.
- Filter by user_id and report_date.

RETRIEVAL TERMS: daily report, daily sales summary, revenue, expenses, profit, bill count, top product, cash collected, UPI collected, card collected.

EXAMPLE QUESTIONS:
- What did the daily report show for yesterday?
- Show daily revenue and expenses this week.
- Which product was top-ranked in the daily report?
