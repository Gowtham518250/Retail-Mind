BUSINESS TABLE CATALOG FOR RETRIEVAL
===================================

This file contains only business/operational tables relevant to sales, inventory, customers, invoices, payment, stock, and shop operations.
It intentionally excludes user authentication, password, session, privacy, and internal auth tables.


1) sales
   Purpose: Daily sales transactions and revenue tracking.
   Key columns:
   - id: primary key
   - shopkeeper_id: owner/shop reference
   - product_name: sold product name
   - price: unit price
   - quantity: number of units sold
   - total: total amount for the sale row
   - sale_date: date of sale
   Example questions:
   - How many sales today?
   - What is today’s revenue?
   - Which product sold most today?

2) products
   Purpose: Product catalog and stock information.
   Key columns:
   - id: primary key
   - product_name: product name
   - sku: unique product code
   - description: product description
   - current_stock: available stock
   - min_stock: minimum alert threshold
   - max_stock: maximum stock limit
   - reorder_level: reorder trigger level
   - unit_price: selling price
   - purchase_price: cost price
   - category: product category
   - is_active: active/inactive status
   Example questions:
   - Which products are low in stock?
   - Show product prices and categories.
   - How much stock is available for product X?

3) stock_movements
   Purpose: Inventory movement and stock change history.
   Key columns:
   - id: primary key
   - product_id: related product
   - movement_type: IN / OUT / ADJUSTMENT
   - quantity: quantity changed
   - reason: reason for movement
   - reference_id: invoice/order reference
   - created_at: movement timestamp
   Example questions:
   - What are recent stock movements?
   - Which items were adjusted today?
   - Show stock in/out history.

4) customers
   Purpose: Customer master data and business relationships.
   Key columns:
   - id: primary key
   - customer_name: customer name
   - email: customer email
   - phone: customer phone
   - whatsapp_number: WhatsApp number
   - address: customer address
   - city: city
   - state: state
   - postal_code: postal code
   - credit_limit: allowed credit
   - payment_terms: credit terms
   - is_active: active status
   Example questions:
   - Who are my top customers?
   - Show customers from a city.
   - List customer contact details.

5) invoices
   Purpose: Billing records and invoice lifecycle.
   Key columns:
   - id: primary key
   - invoice_number: invoice number
   - customer_id: linked customer
   - customer_name: customer display name
   - customer_phone: customer phone
   - invoice_date: invoice date
   - due_date: due date
   - subtotal: before tax amount
   - tax: tax amount
   - total_amount: final invoice total
   - paid_amount: amount already paid
   - status: DRAFT / SENT / PAID / OVERDUE / PARTIAL / CANCELLED
   - payment_status: UNPAID / PARTIAL / PAID / OVERDUE
   - payment_method: method used
   - source: MANUAL_ENTRY / ONLINE_ORDER / OFFLINE_SYNC
   - notes: invoice notes
   Example questions:
   - How many unpaid invoices are there?
   - Show invoices for this month.
   - What is the outstanding amount?

6) payments
   Purpose: Payment records against invoices.
   Key columns:
   - id: primary key
   - invoice_id: invoice reference
   - payment_method: CASH / CARD / TRANSFER / CHEQUE / ONLINE
   - amount: payment amount
   - payment_date: payment timestamp
   - reference_number: transaction reference
   - notes: payment notes
   Example questions:
   - What payments were received today?
   - Which payment method is used the most?
   - Show recent cash and card payments.

7) attendance
   Purpose: Employee worker attendance tracking.
   Key columns:
   - id: primary key
   - employee_id: employee reference
   - worker_id: worker reference
   - attendance_date: attendance date
   - check_in_time: check-in time
   - check_out_time: check-out time
   - status: PRESENT / ABSENT / LATE / LEAVE / HALF_DAY
   - working_hours: total duration
   - notes: notes
   Example questions:
   - Who was present today?
   - Show attendance this week.
   - Calculate working hours by employee.

8) online_orders
   Purpose: Orders placed through the online store.
   Key columns:
   - id: primary key
   - order_number: order number
   - customer_id: related customer
   - status: PENDING / ACCEPTED / DISPATCHED / DELIVERED / REJECTED
   - total_amount: order amount
   - created_at: order creation timestamp
   Example questions:
   - How many online orders are pending?
   - Show delivered online orders today.
   - Which online orders are currently dispatched?

9) whatsapp_orders
   Purpose: Orders received via WhatsApp commerce.
   Key columns:
   - id: primary key
   - customer_name: customer name
   - phone: contact number
   - status: PENDING / ACCEPTED / COMPLETED / REJECTED
   - total_amount: order amount
   - created_at: order creation time
   Example questions:
   - Show WhatsApp orders pending approval.
   - How many WhatsApp orders were completed this month?
   - List recent WhatsApp sales.

10) purchase_orders
    Purpose: Supplier purchase orders and procurement tracking.
    Key columns:
    - id: primary key
    - po_number: purchase order number
    - vendor_name: supplier name
    - status: DRAFT / SENT / DELIVERED / CANCELLED
    - total_amount: order value
    - created_at: order creation time
    Example questions:
    - Which purchase orders are pending delivery?
    - Show procurement spending this month.
    - Which items need restocking?

11) gift_cards
    Purpose: Gift card and voucher lifecycle tracking.
    Key columns:
    - id: primary key
    - card_code: gift card code
    - amount: gift card value
    - status: ACTIVE / REDEEMED / EXPIRED
    - expiry_date: expiration date
    - created_at: creation date
    Example questions:
    - How many gift cards are active?
    - Show redeemed gift card values.
    - Which gift cards expired recently?

12) shop_profiles
    Purpose: Store profile and business identity details.
    Key columns:
    - id: primary key
    - shop_name: shop name
    - shop_phone: shop phone
    - shop_address: store address
    - shop_tagline: business tagline
    - shop_description: description
    Example questions:
    - What is my business profile?
    - Show store contact details.
    - What is the shop name and address?

13) shop_settings
    Purpose: Operational store configuration and preferences.
    Key columns:
    - id: primary key
    - setting_name: configuration key
    - setting_value: configuration value
    - updated_at: last update time
    Example questions:
    - What tax settings are configured?
    - Show business preferences.
    - What invoice settings are active?


EXCLUDED TABLES (NOT USED FOR BUSINESS RETRIEVAL)
--------------------------------------------------
- user_details
- tokens
- refresh_tokens
- notifications
- agent_escalations
- leaves and staff auth data
- any password/session/privacy tables

This catalog is designed for chunking later into retrieval vectors based on a user query.
